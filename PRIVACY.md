# Privacy Policy — Joris Playlist Sorter for YouTube

_Last updated: November 16, 2026_

Joris Playlist Sorter for YouTube does **not** collect, store, transmit, sell or share any data.

- It runs only on `https://www.youtube.com/*` pages.
- It reads the names and IDs of your playlists **inside the page** only to sort and filter them on screen and to link to them (the ↗ "open playlist" button). They never leave your browser.
- It makes no network requests, uses no analytics, and has no remote servers.
- It stores nothing: no cookies, no local storage, no sync storage.
- It does not change your playlists or your YouTube account. Sorting is visual only.

The full source code is public, so anyone can verify this.

If you have questions, please open an issue in the project's GitHub repository.
